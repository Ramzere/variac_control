⚙️ Setup guide — Starting procedure
1
🔌 Cut the motor power supply and place the jaw coupler on the Variac knob. Make sure all 10 teeth are properly seated in the knurls.
2
⚡ Power on the motor supply — then remove the coupler from the knob without rotating it. This sets the reference position.
3
🌡️ Open the CalexConfig application on the computer.
(Sensor A — Low range: CalexConfig)
4
▶️ Start the temperature recording in CalexConfig.
5
🔍 Come back to this interface and run the Autotest. All checks should pass green before continuing.
6
🔧 Place the coupler back on the Variac knob. The system is ready to use.
7
🌡️ Once the autotest is complete, select the correct sensor from the dropdown in the top bar to apply the right temperature limits for your session.
✅ All set — good testing!
Everything is connected and ready. You can now use Manual or Cycle mode.
